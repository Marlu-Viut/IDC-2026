# Análisis Exploratorio de Datos - Inside Airbnb CDMX

Este repositorio contiene la práctica de Análisis Exploratorio de Datos utilizando el dataset de *Inside Airbnb* para la Ciudad de México, con fecha de recopilación del 15 de junio de 2026.

## Descripción del Dataset
El dataset contiene información detallada sobre los listados de alojamiento disponibles en la plataforma Airbnb, específicamente en la CDMX. La cual nos permite analizar la distribución espacial, los precios, la disponibilidad y las características de los alojamientos en la ciudad.

## Requisitos de Ejecución
Para ejecutar el notebook, necesitas tener instalado Python 3.8+ y las siguientes librerías:
- `pandas`
- `numpy`
- `matplotlib`
- `seaborn`
- `missingno`

Puedes instalarlas usando:
`pip install pandas numpy matplotlib seaborn missingno`

## Instrucciones de Uso
1. Clona este repositorio.
2. Descarga el archivo `listings.csv` de [Inside Airbnb](https://insideairbnb.com/get-the-data/) (CDMX, 15 June 2026) y colócalo en la misma carpeta que el notebook.
3. Abre el archivo `Práctica1.ipynb` utilizando Jupyter Notebook, Colab, etc.
4. Ejecuta las celdas en orden.
